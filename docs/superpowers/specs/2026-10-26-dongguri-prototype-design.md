# 돈구리 프로토타입 설계

작성일 2026-10-26 · 기획서 v2와 브레인스토밍 결정 사항을 바탕으로 함

## 목적과 성공 기준

- 12/11 DDP 본선에서 3분 안에 "아낀 돈이 저축과 은행잎 보상으로 돌아오는 하루"를 시연한다.
- 베타 테스트 학생 약 10명이 자기 폰에서 7일 동안 쓸 수 있다.
- 성공 기준
  - 링크 하나로 폰과 노트북(폰 프레임)에서 열린다.
  - 인터넷이 끊기거나 AI 키가 없어도 시연이 멈추지 않는다.
  - 지출 기록 1건은 3탭, 10초 이내.
  - 하루 한도 계산은 자동 테스트로 검증된다.

## 범위

포함(Must 7): 온보딩 4단계, 하루 한도, 지출 기록 3탭, "N원 저축할게요", 일일 퀴즈 + 오답 노트, 은행잎 보상과 상점(액세서리 4 + 한복 4), AI 코치.

제외: 예정 지출·캘린더, 알림 배너, 주간 리포트, 실제 계좌 연동, 서버, 로그인.

## 돈 계산 규칙 (budget.js)

- 주기: 매주(받는 요일) 또는 매월(받는 날짜 1~28). 오늘이 속한 주기의 시작일과 끝일을 구한다.
- 주기 쓸 돈 = 용돈 − 고정 지출 − 주기 저축 목표. 저축 목표는 주기 시작 때 저축통으로 옮긴 것으로 친다.
- 오늘 한도(롤링) = (주기 쓸 돈 − 오늘 이전 지출 − 오늘 이전 추가 저축) ÷ 오늘 포함 남은 일수. 내림, 0 미만이면 0.
- 오늘 남은 돈 = 오늘 한도 − 오늘 지출 − 오늘 추가 저축. 음수면 "N원 넘었어요".
- 한도를 넘긴 금액은 다음 날 계산에 자동으로 나뉘어 반영된다(롤링의 결과).
- "어제 아낀 돈" = 오늘 한도 − 주기 기본 한도(주기 쓸 돈 ÷ 주기 일수)가 양수일 때 표시.
- 목표 진행률 = 저축통 ÷ 목표 금액.
- 연속 기록(스트릭): 어제부터 거꾸로, 지출이 그날 한도 이하였던 날 수. 레벨 = min(8, 1 + ⌊스트릭/3⌋).

| 행동 | 은행잎 |
|---|---|
| 퀴즈 첫 시도 정답 | 3 |
| 오답 노트 다시 풀어 정답 | 1 |

## 화면

1. 온보딩: 돈구리 인사(시작) → ① 용돈 금액·주기·받는 날 → ② 고정 지출(건너뛰기) → ③ 목표 이름·금액·기한, 주기당 저축액 제안(수정 가능) → ④ 결과 "오늘 써도 되는 돈".
2. 홈: 상단 바(돈구리 얼굴·레벨·연속 일수·은행잎), 돈구리 무대(상태별 표정·포즈 + 말풍선), 오늘 쓸 수 있는 돈 카드, 목표 진행 카드, "지출 기록하기"·"N원 저축할게요" 버튼, 오늘 기록 목록(밀어서 삭제 대신 길게 눌러 삭제 확인).
3. 지출 기록 시트: 큰 키패드 → 카테고리 칩 6개(친구 약속 먼저) → 저장. 입력 중 "쓰고 나면 N원 남아요/N원 많아요" 실시간 표시.
4. 저축 시트: 추천 칩(오늘 남은 만큼/1,000/5,000) + 직접 입력, 저장 전 하루 한도 변화 미리보기, 저장 시 은행잎이 저축통으로 날아가는 효과.
5. 퀴즈: 하루 5문제, 진행 바, 3지선다, 정답·해설, 끝나면 결과와 상점 버튼. 오답 노트 탭.
6. 코치: 대화형. 빠른 질문 칩 3개. 키가 있으면 Claude, 없으면 규칙 기반 답변. 답변 아래 하루별 계획 표.
7. 상점: 돈구리 미리보기 + 액세서리 4·한복 4 카드, 구매 확인 시트, 착용/해제.
8. 설정: 예산 수정(저장 전 한도 변화 미리보기), Claude API 키, 시연 데이터 불러오기, 하루 넘기기, 초기화.

## AI 코치

- `@anthropic-ai/sdk@0.133.0`을 jsDelivr ESM으로 불러와 브라우저에서 호출(`dangerouslyAllowBrowser: true`). 키는 기기에만 저장.
- 모델 `claude-opus-5-5`, effort `low`, 서버 측 대체 모델(`fallbacks: "default"`, 베타 `server-side-fallback-2026-07-01`).
- 계산은 앱이 하고 AI는 설명만 한다. 앱이 계산한 남은 돈·일수·계획을 시스템 프롬프트에 넣는다. 이름 등 개인정보는 보내지 않는다.
- 실패(키 없음, 네트워크, 거절)하면 규칙 기반 답변으로 대체하고 "예시 답변" 표시.

## 시연 장치

- 시연 데이터: 김도연, 주 용돈 30,000원, 고정 10,000원, 목표 무선 이어폰 200,000원, 주 저축 15,000원. 2주치 기록, 은행잎 42, 연속 5일.
- 하루 넘기기: 날짜 오프셋 +1. 무지출 보상, 퀴즈 초기화, 한도 재계산이 바로 보인다.

## 오류 처리

- localStorage 접근 실패 → 메모리 저장, 화면 정상.
- 숫자 입력은 정수 원 단위, 0원 지출은 저장 불가.
- 한도 0원 이하 → "0원"과 저축 쉬기/목표 기한 늘리기 안내.
